# agent-trust-contract

Write down what an AI agent may do, what it can never do, and what needs your yes before you connect it to email, calendar, files, money, or accounts, then prove each promise with a test.

**Related reading:** Simon Willison, ["The lethal trifecta"](https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/) · Meta, ["Agents Rule of Two"](https://ai.meta.com/blog/practical-ai-agent-security/)
