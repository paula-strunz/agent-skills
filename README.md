## What is this?

Each folder under [`skills/`](skills) is one skill: a `SKILL.md` (with YAML
frontmatter — a `name` and a trigger `description`) plus any supporting files.
Agents load a skill only when a task matches its description, so skills stay
dormant until they're relevant. Drop them into any agent that reads a `skills/`
directory.

These are **provenance-verified original skills**: my own workflows and
thinking, distilled into reusable form. Personal, voice-specific, premium, and
third-party skills live in a private library and are never mirrored here.

## Use them

```bash
git clone git@github.com:paula-strunz/agent-skills.git ~/repos/agent-skills

# Link every skill into a project's .claude / .agents / .codex folders:
~/repos/agent-skills/install.sh /path/to/project

# ...or link only the ones you need:
~/repos/agent-skills/install.sh /path/to/project --only prime,init-project
```

Skills are symlinked in, so pulling the latest updates them everywhere at once.
